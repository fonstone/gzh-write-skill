# 技术文交付禁令测试样本（合规）

## 问题背景

页表遍历的瓶颈在正确性，不在性能。地址转换缓存未命中时，一次遍历要访问四级页表，每次都是随机内存访问。

实测环境下（Intel i7-12700 + Linux 6.1 x86_64），TLB 未命中路径的 P99 延迟是命中路径的 40 倍。

## 参数表（技术格式，冒号豁免）

| 参数 | 说明 |
|------|------|
| timeout | 超时时间：单位 ms |
| retries | 重试次数：默认 3 |

## 排查步骤

先用 perf 抓一下 page fault 采样。如果采样集中在 walk 函数，问题就在页表遍历，不在缓存。
